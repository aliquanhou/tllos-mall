# 部门管理

## 1. 页面概述
### 功能描述
部门管理页面，支持创建和管理组织部门，配置部门层级、部门负责人、部门状态。部门是组织架构的基础，用于用户归属和权限管理。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 部门总数 | 所有部门数量 | 衡量组织规模 |
| 一级部门 | 顶级部门数量 | 衡量组织划分 |
| 启用部门 | 状态为启用的部门数 | 衡量活跃部门 |
| 部门人数 | 每个部门的用户数量 | 衡量人员分布 |

### 使用场景
1. 部门创建：创建新的组织部门
2. 部门配置：配置部门层级/负责人/状态
3. 部门排序：调整部门显示顺序
4. 部门管理：编辑/禁用/删除部门

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/depts | PermissionController@deptList | 部门列表 | org:dept:list |
| POST | /api/v1/admin/depts | PermissionController@deptStore | 新增部门 | org:dept:create |
| PUT | /api/v1/admin/depts/{id} | PermissionController@deptUpdate | 编辑部门 | org:dept:edit |
| DELETE | /api/v1/admin/depts/{id} | PermissionController@deptDestroy | 删除部门 | org:dept:delete |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| status | int | 否 | 状态 |

### 返回示例
```json
{
  "code":0,
  "data":[
    {"id":1,"name":"技术部","parent_id":0,"leader":"张三","phone":"138****8000","sort":1,"status":1,"user_count":15,"children":[
      {"id":2,"name":"前端组","parent_id":1,"leader":"李四","sort":1,"status":1,"user_count":5}
    ]}
  ]
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |
| 10005 | 部门下有用户不能删除 |

## 4. 操作流程
```
创建部门 → 选择父级 → 填写名称/负责人/电话/排序
├── 部门排序 → 拖拽或输入排序值
├── 编辑部门 → 修改部门属性
├── 禁用部门 → 该部门用户暂时不可用
├── 删除部门 → 该部门下无用户时可删除
└── 用户归属 → 管理员归属到部门
```

### 数据刷新机制
1. 页面加载加载部门树
2. 增删改后刷新部门树
3. 部门变化影响用户归属

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 删除部门失败 | 部门下有用户 | 先转移或删除部门用户 |
| 部门不显示 | 状态为禁用 | 检查部门状态 |
