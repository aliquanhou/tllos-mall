# 商家列表

## 1. 页面概述
### 功能描述
商家列表管理页面，支持查看所有入驻商家、商家详情、商家状态管理、商家信息编辑。商家是多商户商城的核心参与者，每个商家可以独立管理商品和订单。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 商家总数 | 所有商家数量 | 衡量平台规模 |
| 入驻中 | 状态为正常营业的商家数 | 衡量活跃商家 |
| 待审核 | 待审核入驻申请数 | 及时处理提醒 |
| 今日新增 | 今日新增商家数 | 衡量平台增长 |

### 使用场景
1. 商家管理：查看/编辑/禁用商家
2. 入驻审核：审核商家入驻申请
3. 商家分类：管理商家分类
4. 账户日志：查看商家资金变动记录

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/merchants | MerchantController@index | 商家列表 | merchant:list |
| GET | /api/v1/admin/merchants/{id} | MerchantController@show | 商家详情 | merchant:view |
| POST | /api/v1/admin/merchants/{id}/audit | MerchantController@audit | 审核商家 | merchant:audit |
| POST | /api/v1/admin/merchants/{id}/toggle | MerchantController@toggleStatus | 切换状态 | merchant:status |
| PUT | /api/v1/admin/merchants/{id} | MerchantController@update | 编辑商家 | merchant:edit |
| DELETE | /api/v1/admin/merchants/{id} | MerchantController@destroy | 删除商家 | merchant:delete |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码默认1 |
| limit | int | 否 | 每页数量默认20 |
| keyword | string | 否 | 搜索关键词 |
| status | int | 否 | 状态 |
| category_id | int | 否 | 商家分类 |
| start_date | date | 否 | 开始日期 |

### 返回示例
```json
{
  "code":0,
  "data":{"total":45,"page":1,"list":[
    {"id":1,"name":"官方旗舰店","user_id":1,"contact_name":"张三","contact_phone":"13800138000","category_id":1,"category_name":"数码产品","level_id":1,"level_name":"优质商家","status":1,"status_text":"营业中","product_count":156,"order_count":1234,"total_sales":"567890.00","created_at":"2026-08-01"}
```

| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |

## 4. 操作流程
```
商家提交入驻申请 → 待审核状态
├── 管理员审核通过 → 营业中 → 可上架商品和接收订单
├── 管理员审核拒绝 → 已拒绝（通知商家）
├── 管理员禁用 → 已禁用（暂停营业）
├── 商家关闭 → 已关闭（退出平台）
└── 等级调整 → 根据业绩自动升级或手动调整
```

### 数据刷新机制
1. 页面加载加载商家列表
2. 审核/禁用后刷新状态
3. 新申请实时进入待审核列表

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 审核失败 | 商家资料不完整 | 检查商家营业执照和联系方式 |
| 商家看不到商品 | 状态为禁用或未审核通过 | 检查商家状态 |
