# 入驻审核

## 1. 页面概述
### 功能描述
商家入驻审核页面，支持查看所有待审核的商家入驻申请、审核通过或拒绝、查看商家详细资料。入驻审核是保障平台商家质量的重要环节。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 待审核 | 待审核申请数 | 及时处理提醒 |
| 今日申请 | 今日新增申请数 | 衡量平台吸引力 |
| 已通过 | 累计审核通过数 | 衡量入驻转化率 |
| 已拒绝 | 累计审核拒绝数 | 衡量审核严格度 |

### 使用场景
1. 申请审核：审核商家入驻申请
2. 资料查看：查看商家营业执照/身份证等资料
3. 审核记录：查看历史审核记录
4. 拒绝原因：填写拒绝原因并通知商家

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/merchants/audit | MerchantController@index | 待审核列表 | merchant:audit:list |
| POST | /api/v1/admin/merchants/{id}/audit | MerchantController@audit | 审核商家 | merchant:audit |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码默认1 |
| limit | int | 否 | 每页数量默认20 |
| keyword | string | 否 | 搜索关键词 |
| status | int | 否 | 状态 |
| start_date | date | 否 | 开始日期 |
| end_date | date | 否 | 结束日期 |

### 返回示例
```json
{
  "code":0,
  "data":{"total":12,"page":1,"list":[
    {"id":1,"name":"新商家旗舰店","contact_name":"李四","contact_phone":"13900139000","category_id":2,"category_name":"服装鞋包","business_license":"BL202609010001","id_card":"3702**********1234","status":0,"status_text":"待审核","apply_time":"2026-09-01 10:00:00"}
  ]}
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |
| 10005 | 申请已审核不能重复审核 |
| 10006 | 拒绝时必须填写拒绝原因 |

## 4. 操作流程
```
商家提交入驻申请 → 填写资料（名称/联系人/营业执照/身份证）
├── 管理员查看申请详情 → 核对资料真实性
│   ├── 审核通过 → 创建商家账号 → 通知商家
│   └── 审核拒绝 → 填写拒绝原因 → 通知商家
└── 商家可重新提交申请
```

### 数据刷新机制
1. 页面加载加载待审核列表
2. 审核后刷新列表
3. 新申请实时进入列表

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 审核通过后商家无法登录 | 账号未创建或密码错误 | 检查商家账号创建逻辑 |
| 营业执照图片不显示 | 图片路径错误或存储配置问题 | 检查存储配置和图片URL |
