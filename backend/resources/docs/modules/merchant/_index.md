# 商家管理

## 1. 模块概述
商家管理是多商户商城的核心模块，管理平台所有入驻商家的全生命周期，包括商家入驻审核、信息管理、分类分级、资金账户、菜单权限等。商家是商品和订单的主体，每个商家拥有独立的商品、订单、财务体系。

## 4. 商家状态机
0=待审核 → 1=已通过（正常经营）
0=待审核 → 2=已拒绝
1=已通过 → 3=已禁用（平台禁用）
3=已禁用 → 1=已通过（解除禁用）
