# 用户列表

## 1. 页面概述
### 功能描述
用户列表管理页面，支持查看所有注册用户、用户详情、用户状态管理、用户信息编辑。用户是商城的核心参与者，所有交易行为都围绕用户展开。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 用户总数 | 所有注册用户数 | 衡量平台规模 |
| 今日新增 | 今日新注册用户数 | 衡量增长趋势 |
| 活跃用户 | 近期有登录或下单的用户数 | 衡量用户活跃度 |
| 禁用用户 | 状态为禁用的用户数 | 风险用户监控 |

### 使用场景
1. 用户管理：查看/编辑/禁用用户
2. 用户查询：按手机号/昵称/注册时间筛选
3. 用户详情：查看用户订单/余额/积分等信息
4. 状态管理：禁用违规用户或恢复正常用户

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/users | AdminUserController@index | 用户列表 | user:list |
| GET | /api/v1/admin/users/{id} | AdminUserController@show | 用户详情 | user:view |
| POST | /api/v1/admin/users/{id}/toggle | AdminUserController@toggleStatus | 切换状态 | user:status |
| PUT | /api/v1/admin/users/{id} | AdminUserController@update | 编辑用户 | user:edit |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码默认1 |
| limit | int | 否 | 每页数量默认20 |
| keyword | string | 否 | 搜索关键词 |
| phone | string | 否 | 手机号 |
| nickname | string | 否 | 昵称 |
| status | int | 否 | 状态 |
| start_date | date | 否 | 注册开始日期 |
| end_date | date | 否 | 注册结束日期 |

### 返回示例
```json
{
  "code":0,
  "data":{"total":12345,"page":1,"list":[
    {"id":1,"nickname":"张三","phone":"138****8000","avatar":"https://.../avatar.jpg","gender":1,"status":1,"status_text":"正常","balance":"1234.50","points":5600,"total_orders":45,"total_amount":"23456.00","last_login_at":"2026-09-01 10:00:00","created_at":"2026-08-01"}
  ]}
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |
| 10005 | 用户状态不允许此操作 |
| 10006 | 手机号已被使用 |

## 4. 操作流程
```
用户注册 → 正常状态
├── 用户登录 → 更新最后登录时间
├── 用户下单 → 订单数+1，消费金额增加
├── 用户充值 → 余额增加
├── 用户积分 → 下单/签到获得积分
├── 管理员禁用 → 状态变为禁用（无法登录和下单）
└── 管理员恢复 → 状态恢复正常
```

### 数据刷新机制
1. 页面加载加载用户列表
2. 状态变更后刷新
3. 用户数据准实时更新

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 用户无法登录 | 状态为禁用或密码错误 | 检查用户状态和密码重置 |
| 用户余额不对 | 充值或消费记录异常 | 检查用户账户日志 |
