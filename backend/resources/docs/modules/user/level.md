# 用户等级

## 1. 页面概述
### 功能描述
用户等级管理页面，支持创建和管理用户等级，配置不同等级的成长值要求、折扣率、专属权益。用户等级体系是激励用户消费和提升忠诚度的重要机制。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 等级总数 | 所有用户等级数 | 衡量等级体系 |
| 启用等级 | 状态为启用的等级数 | 衡量可用等级 |
| 等级用户数 | 每个等级的用户数量 | 衡量等级分布 |

### 使用场景
1. 等级配置：创建不同等级的成长值要求和折扣率
2. 权益配置：配置不同等级的专属权益
3. 等级调整：手动调整用户等级
4. 升级规则：配置自动升级条件

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/user-levels | UserLevelController@index | 等级列表 | user:level:list |
| POST | /api/v1/admin/user-levels | UserLevelController@store | 新增等级 | user:level:create |
| PUT | /api/v1/admin/user-levels/{id} | UserLevelController@update | 编辑等级 | user:level:edit |
| DELETE | /api/v1/admin/user-levels/{id} | UserLevelController@destroy | 删除等级 | user:level:delete |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码默认1 |
| limit | int | 否 | 每页数量默认20 |
| keyword | string | 否 | 搜索关键词 |
| status | int | 否 | 状态 |

### 返回示例
```json
{
  "code":0,
  "data":{"total":5,"list":[
    {"id":1,"name":"普通会员","level":1,"growth_required":0,"discount_rate":"100.00","status":1,"sort":1,"description":"注册即成为普通会员","user_count":8900,"created_at":"2026-08-01"},
    {"id":2,"name":"白银会员","level":2,"growth_required":1000,"discount_rate":"98.00","status":1,"sort":2,"description":"成长值达到1000升级","user_count":2300}
  ]}
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |
| 10005 | 等级下有用户不能删除 |
| 10006 | 等级级别不能重复 |

## 4. 操作流程
```
创建用户等级 → 配置成长值要求/折扣率/权益
├── 用户消费获得成长值 → 达到升级条件 → 自动升级
├── 管理员手动调整用户等级
├── 等级禁用 → 该等级不可用（已有用户保留等级）
└── 等级删除 → 该等级下无用户时可删除
```

### 数据刷新机制
1. 页面加载加载等级列表
2. 增删改后刷新列表
3. 等级变化影响用户折扣计算

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 删除等级失败 | 等级下有用户 | 先转移或调整用户等级 |
| 折扣不生效 | 缓存未清除或等级配置错误 | 清除缓存检查等级配置 |
