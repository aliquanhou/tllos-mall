# 商品列表

## 1. 页面概述
### 功能描述
商品列表页是商城商品管理的核心页面，支持商品的增删改查、上下架、批量操作、搜索筛选。管理员可以在此管理所有商品信息，包括SKU、库存、价格、图片、视频等。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 商品总数 | 所有商品数量 | 衡量商品库规模 |
| 在售商品 | 上架状态商品数 | 衡量可售数量 |
| 库存预警 | 库存低于阈值商品数 | 及时补货提醒 |
| 今日新增 | 今日新创建商品数 | 衡量运营活跃度 |

### 使用场景
1. 日常商品管理：新增/编辑/上下架商品
2. 库存管理：查看库存预警，及时补货
3. 运营活动：批量上下架参与活动商品
4. 数据统计：查看商品销量和表现

## 2. API接口清单
| 方法 | 路径 | 说明 | 权限标识 |
|------|------|------|----------|
| GET | /api/v1/admin/products | 获取商品列表 | product:list |
| POST | /api/v1/admin/products | 新增商品 | product:create |
| GET | /api/v1/admin/products/{id} | 商品详情 | product:view |
| PUT | /api/v1/admin/products/{id} | 编辑商品 | product:edit |
| DELETE | /api/v1/admin/products/{id} | 删除商品 | product:delete |
| POST | /api/v1/admin/products/batch | 批量操作 | product:batch |
| GET | /api/v1/admin/products/{id}/skus | SKU列表 | product:sku:list |
| POST | /api/v1/admin/products/{id}/skus | 新增SKU | product:sku:create |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码，默认1 |
| limit | int | 否 | 每页数量，默认20 |
| keyword | string | 否 | 搜索关键词 |
| category_id | int | 否 | 分类ID |
| status | int | 否 | 状态0下架1上架 |
| merchant_id | int | 否 | 商家ID |
| sort | string | 否 | 排序字段 |

### 返回示例
```json
{
  "code": 0,
  "data": {
    "total": 156,
    "page": 1,
    "list": [{"id":1001,"name":"华为 MatePad Pro","price":"5199.00","stock":2269,"sales":4947,"status":1}]
  }
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |
| 10005 | 库存不能为负数 |
| 10006 | 商品分类不存在 |

## 4. 操作流程
```
进入商品列表 → 搜索/筛选 → 查看列表
├── 新增商品 → 基本信息 → 上传图片/视频 → 编辑详情 → 设置SKU → 保存上架
├── 编辑商品 → 回显信息 → 修改字段 → 保存
├── 批量操作 → 勾选商品 → 批量上下架/删除
└── 删除商品 → 确认弹窗 → 软删除 → 列表刷新
```

### 数据刷新机制
1. 页面加载自动请求
2. 搜索筛选变化立即刷新
3. 增删改后自动刷新
4. 库存实时同步

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件，确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验，查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除或软删除状态 | 清除缓存，检查删除状态 |
| 图片上传失败 | 文件超限或格式不支持 | 检查存储配置，支持jpg/png/webp≤5MB |
| SKU库存为0仍可购买 | 库存校验缺失 | 下单时校验SKU库存 |
