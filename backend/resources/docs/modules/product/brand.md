# 品牌管理

## 1. 页面概述
### 功能描述
品牌管理页面，支持品牌的增删改查、logo上传、排序、状态管理。品牌是商品的重要属性，影响商品展示和用户筛选。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 品牌总数 | 所有品牌数量 | 衡量品牌库规模 |
| 启用品牌 | 状态为启用的品牌数 | 衡量可用品牌 |
| 关联商品 | 有商品的品牌数 | 衡量品牌使用率 |
| 今日新增 | 今日新增品牌数 | 衡量品牌拓展 |

### 使用场景
1. 品牌库建设：录入合作品牌
2. 品牌维护：更新品牌logo和介绍
3. 品牌禁用：暂停合作品牌
4. 商品关联：商品选择品牌

## 2. API接口清单
| 方法 | 路径 | 说明 | 权限标识 |
|------|------|------|----------|
| GET | /api/v1/admin/brands | 品牌列表 | brand:list |
| POST | /api/v1/admin/brands | 新增品牌 | brand:create |
| PUT | /api/v1/admin/brands/{id} | 编辑品牌 | brand:edit |
| DELETE | /api/v1/admin/brands/{id} | 删除品牌 | brand:delete |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码，默认1 |
| limit | int | 否 | 每页数量，默认20 |
| keyword | string | 否 | 搜索关键词 |
| status | int | 否 | 状态 |
| first_letter | string | 否 | 首字母筛选 |

### 返回示例
```json
{
  "code": 0,
  "data": {"total":45,"page":1,"list":[
    {"id":1,"name":"华为","logo":"https://.../huawei.png","first_letter":"H","sort":1,"status":1,"product_count":156}
  ]}
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |
| 10005 | 品牌下有商品不能删除 |

## 4. 操作流程
```
进入品牌管理 → 查看品牌列表
├── 新增品牌 → 填写名称/上传logo/选择首字母/排序 → 保存
├── 编辑品牌 → 修改信息 → 保存
├── 删除品牌 → 检查是否有商品 → 确认删除
└── 状态切换 → 启用/禁用品牌
```

### 数据刷新机制
1. 页面加载加载品牌列表
2. 增删改后刷新列表
3. 品牌变化影响商品选择选项

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件，确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验，查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除或软删除状态 | 清除缓存，检查删除状态 |
| 品牌logo不显示 | 图片路径错误 | 检查存储配置和图片URL |
| 删除品牌失败 | 品牌下有商品 | 先转移或删除关联商品 |
