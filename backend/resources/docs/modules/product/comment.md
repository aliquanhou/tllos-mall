# 商品评价

## 1. 页面概述
### 功能描述
商品评价管理页面，支持查看用户对商品的评价、审核评价、回复评价、删除违规评价。评价管理是维护商城口碑的重要功能。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 评价总数 | 所有评价数量 | 衡量用户活跃度 |
| 待审核 | 待审核评价数 | 及时处理审核 |
| 好评率 | 好评占比 | 衡量商品口碑 |
| 今日新增 | 今日新增评价数 | 衡量近期活跃度 |

### 使用场景
1. 评价审核：审核用户提交的评价
2. 评价回复：商家回复用户评价
3. 违规处理：删除广告/恶意评价
4. 口碑监控：查看商品好评率

## 2. API接口清单
| 方法 | 路径 | 说明 | 权限标识 |
|------|------|------|----------|
| GET | /api/v1/admin/comments | 评价列表 | comment:list |
| GET | /api/v1/admin/comments/{id} | 评价详情 | comment:view |
| PUT | /api/v1/admin/comments/{id} | 审核评价 | comment:audit |
| POST | /api/v1/admin/comments/{id}/reply | 回复评价 | comment:reply |
| DELETE | /api/v1/admin/comments/{id} | 删除评价 | comment:delete |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码，默认1 |
| limit | int | 否 | 每页数量，默认20 |
| keyword | string | 否 | 搜索关键词 |
| product_id | int | 否 | 商品ID |
| user_id | int | 否 | 用户ID |
| status | int | 否 | 状态0待审1通过2拒绝 |
| rating | int | 否 | 评分1-5 |

### 返回示例
```json
{
  "code": 0,
  "data": {"total":89,"page":1,"list":[
    {"id":1,"product_id":1001,"product_name":"华为 MatePad","user_id":1,"user_name":"张三","rating":5,"content":"非常好！","images":[],"status":1,"reply":"感谢支持","created_at":"2026-08-01"}
  ]}
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |
| 10005 | 评价已审核不能重复审核 |
| 10006 | 回复内容不能为空 |

## 4. 操作流程
```
用户提交评价 → 待审核状态
├── 管理员审核 → 通过 → 展示在商品页
│              → 拒绝 → 不展示，通知用户
├── 商家回复 → 填写回复内容 → 保存展示
└── 违规处理 → 删除评价 → 记录操作日志
```

### 数据刷新机制
1. 页面加载加载评价列表
2. 审核/回复/删除后刷新列表
3. 新评价实时进入待审核

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件，确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验，查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除或软删除状态 | 清除缓存，检查删除状态 |
| 评价图片不显示 | 图片路径错误或已删除 | 检查图片存储和URL |
| 用户看不到评价 | 评价未审核通过 | 检查评价状态，确保已审核通过 |
