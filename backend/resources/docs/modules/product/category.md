# 商品分类

## 1. 页面概述
### 功能描述
商品分类管理页面，支持分类的树形结构管理、增删改查、排序、图标设置。分类是商品组织的基础，影响前端导航和商品筛选。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 分类总数 | 所有分类数量 | 衡量分类体系规模 |
| 一级分类 | 顶级分类数量 | 衡量大类划分 |
| 有商品分类 | 关联了商品的分类数 | 衡量分类使用率 |
| 禁用分类 | 状态为禁用的分类数 | 待清理分类 |

### 使用场景
1. 分类体系搭建：创建多级分类树
2. 分类调整：修改分类名称/图标/排序
3. 分类禁用：临时下架某类商品
4. 商品归类：商品选择对应分类

## 2. API接口清单
| 方法 | 路径 | 说明 | 权限标识 |
|------|------|------|----------|
| GET | /api/v1/admin/categories | 分类树 | category:list |
| POST | /api/v1/admin/categories | 新增分类 | category:create |
| PUT | /api/v1/admin/categories/{id} | 编辑分类 | category:edit |
| DELETE | /api/v1/admin/categories/{id} | 删除分类 | category:delete |
| POST | /api/v1/admin/categories/sort | 分类排序 | category:sort |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码 |
| limit | int | 否 | 每页数量 |
| parent_id | int | 否 | 父分类ID |
| status | int | 否 | 状态 |

### 返回示例
```json
{
  "code": 0,
  "data": [
    {"id":1,"name":"数码产品","parent_id":0,"sort":1,"status":1,"children":[
      {"id":5,"name":"平板电脑","parent_id":1,"sort":1,"status":1}
    ]}
  ]
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |
| 10005 | 分类下有商品不能删除 |
| 10006 | 父分类不存在 |

## 4. 操作流程
```
进入分类管理 → 查看分类树
├── 新增分类 → 选择父分类 → 填写名称/图标/排序 → 保存
├── 编辑分类 → 修改名称/图标/排序 → 保存
├── 删除分类 → 检查是否有子分类/商品 → 确认删除
└── 排序调整 → 拖拽或输入排序值 → 保存排序
```

### 数据刷新机制
1. 页面加载加载分类树
2. 增删改后刷新树形结构
3. 分类变化影响商品列表筛选选项

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件，确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验，查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除或软删除状态 | 清除缓存，检查删除状态 |
| 删除分类失败 | 分类下有商品或子分类 | 先转移商品或删除子分类 |
| 分类图标不显示 | 图片路径错误或CDN配置 | 检查存储配置和图片URL |
