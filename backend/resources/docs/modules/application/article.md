# 文章资讯

## 1. 页面概述
### 功能描述
文章资讯管理页面，支持创建和管理文章资讯，包括文章分类、文章内容、封面图、发布状态。文章资讯是商城内容运营的重要工具，用于发布公告、资讯、帮助文档等。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 文章总数 | 所有文章数量 | 衡量内容规模 |
| 已发布 | 状态为已发布的文章数 | 衡量公开内容 |
| 待发布 | 草稿状态的文章数 | 衡量待处理内容 |
| 今日新增 | 今日新增文章数 | 衡量内容产出 |

### 使用场景
1. 文章创建：撰写新的文章资讯
2. 文章编辑：修改文章内容和设置
3. 文章分类：管理文章分类
4. 发布管理：控制文章发布状态和时间

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/articles | AdminArticleController@index | 文章列表 | article:list |
| POST | /api/v1/admin/articles | AdminArticleController@store | 新增文章 | article:create |
| GET | /api/v1/admin/articles/{id} | AdminArticleController@show | 文章详情 | article:view |
| PUT | /api/v1/admin/articles/{id} | AdminArticleController@update | 编辑文章 | article:edit |
| DELETE | /api/v1/admin/articles/{id} | AdminArticleController@destroy | 删除文章 | article:delete |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码默认1 |
| limit | int | 否 | 每页数量默认20 |
| keyword | string | 否 | 搜索关键词 |
| category_id | int | 否 | 分类ID |
| status | int | 否 | 状态 |
| start_date | date | 否 | 开始日期 |

### 返回示例
```json
{
  "code":0,
  "data":{"total":56,"page":1,"list":[
    {"id":1,"title":"商城9月促销活动公告","category_id":1,"category_name":"商城公告","cover":"https://.../cover.jpg","summary":"9月1日-9月30日，全场满减活动...","author":"管理员","views":1234,"status":1,"status_text":"已发布","published_at":"2026-09-01 10:00:00","created_at":"2026-08-25"}
  ]}
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |
| 10005 | 文章已发布不能删除 |

## 4. 操作流程
```
创建文章 → 填写标题/分类/封面/摘要/内容
├── 保存草稿 → 状态为草稿（不公开）
├── 立即发布 → 状态为已发布（公开可见）
├── 定时发布 → 到指定时间自动发布
├── 编辑文章 → 修改内容 → 保存（已发布文章需重新发布）
├── 下架文章 → 状态为下架（不公开）
└── 删除文章 → 草稿状态可删除，已发布需先下架
```

### 数据刷新机制
1. 页面加载加载文章列表
2. 增删改后刷新列表
3. 浏览量准实时更新

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 文章内容不显示 | 富文本HTML被过滤 | 检查富文本编辑器配置和XSS过滤 |
| 封面图不显示 | 图片路径错误或存储配置问题 | 检查存储配置和图片URL |
