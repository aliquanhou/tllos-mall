# 分销订单

## 1. 页面概述
### 功能描述
分销订单管理页面，支持查看所有通过分销链接产生的订单、佣金计算、结算状态。分销订单是佣金结算的依据。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 分销订单总数 | 所有分销订单数 | 衡量分销转化 |
| 待结算订单 | 待结算的分销订单数 | 及时结算提醒 |
| 已结算订单 | 已完成结算的订单数 | 衡量结算效率 |
| 佣金总额 | 所有分销订单佣金总和 | 衡量分销成本 |

### 使用场景
1. 订单查询：查看所有分销订单
2. 佣金核对：核对每笔订单的佣金计算
3. 结算管理：查看订单结算状态
4. 异常处理：处理佣金计算异常的订单

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/distribute/orders | DistributeController@orders | 分销订单列表 | distribute:order:list |
| GET | /api/v1/admin/distribute/goods | DistributeController@goods | 分销商品列表 | distribute:goods:list |
| POST | /api/v1/admin/distribute/goods/{id}/toggle | DistributeController@goodsToggle | 切换分销商品 | distribute:goods:toggle |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码默认1 |
| limit | int | 否 | 每页数量默认20 |
| keyword | string | 否 | 搜索关键词 |
| order_no | string | 否 | 订单号 |
| distributor_id | int | 否 | 分销商ID |
| settle_status | int | 否 | 结算状态 |
| start_date | date | 否 | 开始日期 |
| end_date | date | 否 | 结束日期 |

### 返回示例
```json
{
  "code":0,
  "data":{"total":1234,"page":1,"list":[
    {"id":1,"order_no":"TLL202609010001","distributor_id":1,"distributor_name":"张三","product_name":"华为 MatePad","order_amount":"5199.00","commission_rate":"10.00","commission":"519.90","settle_status":0,"settle_status_text":"待结算","created_at":"2026-09-01 10:00:00"}
  ]}
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |
| 10005 | 订单结算状态不允许此操作 |
| 10006 | 佣金计算异常 |

## 4. 操作流程
```
用户通过分销链接下单 → 订单标记为分销订单
├── 订单支付成功 → 计算佣金（按比例）→ 佣金入账（待结算）
│   ├── 订单完成（确认收货后N天）→ 佣金可结算
│   │   └── 分销商申请提现 → 管理员审核 → 佣金结算完成
│   └── 订单退款 → 佣金取消
└── 分销订单列表实时更新
```

### 数据刷新机制
1. 页面加载加载分销订单列表
2. 新订单实时进入列表
3. 结算状态变化后刷新

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 佣金金额不对 | 佣金比例配置错误 | 检查分销等级和商品佣金比例 |
| 订单未标记为分销订单 | 分销链接参数丢失 | 检查分销链接生成逻辑 |
