# 轮播图管理

## 1. 页面概述
### 功能描述
轮播图管理页面，支持管理商城首页和各页面的轮播图，包括图片上传、链接设置、排序、状态管理。轮播图是商城首页最重要的广告位，用于展示促销活动和重点商品。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 轮播图总数 | 所有轮播图数量 | 衡量广告位规模 |
| 启用中 | 状态为启用的轮播图数 | 衡量当前展示 |
| 位置数 | 轮播图位置数量 | 衡量广告位分布 |
| 点击率 | 轮播图点击比例 | 衡量广告效果 |

### 使用场景
1. 轮播图管理：新增/编辑/删除轮播图
2. 图片上传：上传轮播图图片
3. 链接设置：设置点击跳转链接
4. 排序管理：调整轮播图显示顺序

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/banners | BannerController@index | 轮播图列表 | banner:list |
| POST | /api/v1/admin/banners | BannerController@store | 新增轮播图 | banner:create |
| PUT | /api/v1/admin/banners/{id} | BannerController@update | 编辑轮播图 | banner:edit |
| DELETE | /api/v1/admin/banners/{id} | BannerController@destroy | 删除轮播图 | banner:delete |
| POST | /api/v1/admin/banners/sort | BannerController@sort | 轮播图排序 | banner:sort |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码默认1 |
| limit | int | 否 | 每页数量默认20 |
| keyword | string | 否 | 搜索关键词 |
| position | string | 否 | 位置 |
| status | int | 否 | 状态 |

### 返回示例
```json
{
  "code":0,
  "data":{"total":6,"list":[
    {"id":1,"title":"9月促销活动","position":"home","image":"https://.../banner1.jpg","link_type":"url","link_value":"https://.../promotion","sort":1,"status":1,"start_time":"2026-09-01 00:00:00","end_time":"2026-09-30 23:59:59","click_count":1234,"created_at":"2026-08-25"}
  ]}
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |
| 10005 | 图片上传失败 |
| 10006 | 链接格式错误 |

## 4. 操作流程
```
进入轮播图管理 → 选择位置
├── 新增轮播图 → 上传图片 → 设置标题/链接/排序/时间
├── 编辑轮播图 → 修改图片/链接/排序
├── 排序调整 → 拖拽或输入排序值
├── 启用/禁用 → 控制是否展示
├── 定时展示 → 在指定时间段内展示
└── 删除轮播图 → 确认删除
```

### 数据刷新机制
1. 页面加载加载轮播图列表
2. 增删改后刷新列表
3. 点击数准实时更新

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 轮播图不显示 | 状态为禁用或不在展示时间内 | 检查状态和展示时间 |
| 图片不显示 | 图片路径错误或存储配置问题 | 检查存储配置和图片URL |
