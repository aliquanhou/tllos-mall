# 拼团活动

## 1. 页面概述
### 功能描述
拼团活动管理页面，支持创建和管理拼团活动，包括拼团价格、成团人数、拼团时长、拼团商品。拼团是社交电商的重要工具，通过用户分享邀请好友成团。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 活动总数 | 所有拼团活动数 | 衡量拼团规模 |
| 进行中 | 进行中的活动数 | 衡量活跃拼团 |
| 拼团商品 | 参与拼团的商品数 | 衡量商品覆盖 |
| 成团数 | 累计成功成团数 | 衡量拼团效果 |
| 拼团金额 | 累计拼团金额 | 衡量拼团产出 |

### 使用场景
1. 活动创建：创建新的拼团活动
2. 商品配置：选择拼团商品和拼团价格
3. 规则配置：设置成团人数和拼团时长
4. 活动管理：编辑/禁用/删除拼团活动

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/groups | AdminGroupController@index | 拼团活动列表 | group:list |
| POST | /api/v1/admin/groups | AdminGroupController@store | 新增拼团活动 | group:create |
| GET | /api/v1/admin/groups/{id} | AdminGroupController@show | 拼团活动详情 | group:view |
| PUT | /api/v1/admin/groups/{id} | AdminGroupController@update | 编辑拼团活动 | group:edit |
| DELETE | /api/v1/admin/groups/{id} | AdminGroupController@destroy | 删除拼团活动 | group:delete |
| GET | /api/v1/admin/group-opens | PtOpenController@index | 拼团开团列表 | group:open:list |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码默认1 |
| limit | int | 否 | 每页数量默认20 |
| keyword | string | 否 | 搜索关键词 |
| status | int | 否 | 状态 |
| start_date | date | 否 | 开始日期 |
| end_date | date | 否 | 结束日期 |

### 返回示例
```json
{
  "code":0,
  "data":{"total":12,"page":1,"list":[
    {"id":1,"name":"好友拼团更优惠","product_id":1001,"product_name":"华为 MatePad","group_price":"4799.00","original_price":"5199.00","group_num":3,"group_hours":24,"status":1,"status_text":"进行中","start_time":"2026-09-01 00:00:00","end_time":"2026-09-30 23:59:59","total_groups":156,"success_groups":89,"created_at":"2026-08-25"}
  ]}

```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |

## 4. 操作流程
```
创建拼团活动 → 配置商品/拼团价格/成团人数/时长
├── 用户开团 → 支付拼团价格 → 生成拼团订单
│   ├── 分享邀请好友 → 好友参团支付
│   ├── 达到成团人数 → 成团成功 → 订单生效
│   └── 超时未成团 → 自动退款
├── 活动进行中 → 用户可开团和参团
└── 活动结束 → 不可开团
```

### 数据刷新机制
1. 页面加载加载拼团活动列表
2. 增删改后刷新列表
3. 开团/成团数据准实时更新

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 拼团失败自动退款 | 超时未成团系统自动退款 | 检查退款状态和支付渠道 |
| 用户看不到拼团活动 | 活动未开始或已禁用 | 检查活动状态和时间 |
