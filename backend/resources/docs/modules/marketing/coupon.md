# 优惠券管理

## 1. 页面概述
### 功能描述
优惠券管理页面，支持创建和管理优惠券，包括满减券、折扣券、无门槛券等类型，支持发放、领取、使用记录查询。优惠券是电商营销的核心工具。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 优惠券总数 | 所有优惠券数量 | 衡量营销活动规模 |
| 进行中 | 状态为进行中的优惠券数 | 衡量活跃活动 |
| 已发放 | 累计发放优惠券数 | 衡量触达用户数 |
| 已使用 | 累计使用优惠券数 | 衡量转化效果 |
| 优惠金额 | 累计优惠金额 | 衡量营销成本 |

### 使用场景
1. 活动创建：创建新的优惠券活动
2. 优惠券发放：手动发放或用户领取
3. 使用记录：查看优惠券使用情况
4. 活动管理：编辑/禁用/删除优惠券

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/coupons | CouponController@index | 优惠券列表 | coupon:list |
| POST | /api/v1/admin/coupons | CouponController@store | 新增优惠券 | coupon:create |
| GET | /api/v1/admin/coupons/{id} | CouponController@show | 优惠券详情 | coupon:view |
| PUT | /api/v1/admin/coupons/{id} | CouponController@update | 编辑优惠券 | coupon:edit |
| POST | /api/v1/admin/coupons/{id}/toggle | CouponController@toggleStatus | 切换状态 | coupon:status |
| DELETE | /api/v1/admin/coupons/{id} | CouponController@destroy | 删除优惠券 | coupon:delete |
| GET | /api/v1/admin/coupons/records | CouponController@records | 领取/使用记录 | coupon:record |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码默认1 |
| limit | int | 否 | 每页数量默认20 |
| keyword | string | 否 | 搜索关键词 |
| type | int | 否 | 类型1满减2折扣3无门槛 |
| status | int | 否 | 状态 |
| start_date | date | 否 | 开始日期 |
| end_date | date | 否 | 结束日期 |

### 返回示例
```json
{
  "code":0,
  "data":{"total":23,"page":1,"list":[
    {"id":1,"name":"新人专享满100减20","type":1,"type_text":"满减券","amount":"20.00","min_amount":"100.00","discount_rate":null,"total_count":1000,"received_count":256,"used_count":128,"status":1,"start_time":"2026-09-01 00:00:00","end_time":"2026-09-30 23:59:59","created_at":"2026-08-25"}
  ]}
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |
| 10005 | 优惠券已结束不能编辑 |
| 10006 | 优惠券库存不足 |

## 4. 操作流程
```
创建优惠券 → 配置类型/金额/门槛/有效期/库存
├── 用户领取优惠券 → 领取记录
│   ├── 用户下单使用优惠券 → 订单享受优惠 → 使用记录
│   └── 优惠券过期 → 未使用的失效
├── 管理员手动发放 → 指定用户发放
├── 管理员禁用 → 优惠券不可领取和使用
└── 优惠券结束 → 状态自动变为已结束
```

### 数据刷新机制
1. 页面加载加载优惠券列表
2. 增删改后刷新列表
3. 领取/使用数据准实时更新

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 用户领不到优惠券 | 库存不足或已过期 | 检查库存和有效期 |
| 优惠券不生效 | 使用条件不满足或商品不支持 | 检查满减门槛和商品范围 |
