# 限时秒杀

## 1. 页面概述
### 功能描述
限时秒杀管理页面，支持创建和管理秒杀活动，包括活动时间、秒杀商品、秒杀价格、库存限制。秒杀是电商促销的重要工具，能快速提升销量和流量。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 活动总数 | 所有秒杀活动数 | 衡量促销规模 |
| 进行中 | 进行中的活动数 | 衡量活跃促销 |
| 秒杀商品 | 参与秒杀的商品数 | 衡量商品覆盖 |
| 秒杀销量 | 累计秒杀订单数 | 衡量促销效果 |
| 秒杀金额 | 累计秒杀金额 | 衡量促销产出 |

### 使用场景
1. 活动创建：创建新的秒杀活动
2. 商品配置：选择秒杀商品和秒杀价格
3. 库存管理：设置秒杀库存
4. 活动管理：编辑/禁用/删除秒杀活动

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/seckills | AdminSeckillController@index | 秒杀活动列表 | seckill:list |
| POST | /api/v1/admin/seckills | AdminSeckillController@store | 新增秒杀活动 | seckill:create |
| GET | /api/v1/admin/seckills/{id} | AdminSeckillController@show | 秒杀活动详情 | seckill:view |
| PUT | /api/v1/admin/seckills/{id} | AdminSeckillController@update | 编辑秒杀活动 | seckill:edit |
| DELETE | /api/v1/admin/seckills/{id} | AdminSeckillController@destroy | 删除秒杀活动 | seckill:delete |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码默认1 |
| limit | int | 否 | 每页数量默认20 |
| keyword | string | 否 | 搜索关键词 |
| status | int | 否 | 状态 |
| start_date | date | 否 | 开始日期 |
| end_date | date | 否 | 结束日期 |

### 返回示例
```json
{
  "code":0,
  "data":{"total":8,"page":1,"list":[
    {"id":1,"name":"9月开学季秒杀","start_time":"2026-09-01 10:00:00","end_time":"2026-09-01 12:00:00","status":1,"status_text":"进行中","products":[{"product_id":1001,"product_name":"华为 MatePad","seckill_price":"4599.00","original_price":"5199.00","seckill_stock":100,"sold_count":45}],"created_at":"2026-08-25"}
  ]}
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |
| 10005 | 活动已开始不能编辑 |
| 10006 | 秒杀价格不能高于原价 |

## 4. 操作流程
```
创建秒杀活动 → 配置活动时间
├── 添加秒杀商品 → 选择商品 → 设置秒杀价格/库存
├── 活动开始 → 用户可购买秒杀商品（限购）
│   ├── 库存扣减 → 秒杀库存减少
│   └── 活动结束 → 不可购买
├── 活动未开始 → 可编辑商品和价格
└── 管理员禁用 → 活动暂停
```

### 数据刷新机制
1. 页面加载加载秒杀活动列表
2. 增删改后刷新列表
3. 秒杀库存实时更新

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 用户买不到秒杀商品 | 库存已售罄或活动未开始 | 检查库存和活动时间 |
| 秒杀价格不显示 | 活动未开始或商品配置错误 | 检查活动状态和商品配置 |
