# 订单列表

## 1. 页面概述
### 功能描述
订单列表页是商城订单管理的核心页面，支持查看所有订单、订单详情、发货、备注、筛选搜索。管理员可以在此处理订单全生命周期。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 订单总数 | 所有订单数量 | 衡量交易规模 |
| 待发货 | 待发货订单数 | 及时发货提醒 |
| 待付款 | 待付款订单数 | 催付提醒 |
| 今日订单 | 今日新增订单数 | 衡量当日交易 |

### 使用场景
1. 订单处理：查看待发货订单并发货
2. 订单查询：按订单号/用户/状态筛选
3. 订单备注：添加内部备注信息
4. 售后处理：查看退款申请

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/orders | AdminOrderController@index | 获取订单列表 | order:list |
| GET | /api/v1/admin/orders/{id} | AdminOrderController@show | 订单详情 | order:view |
| POST | /api/v1/admin/orders/{id}/ship | AdminOrderController@ship | 订单发货 | order:ship |
| POST | /api/v1/admin/orders/{id}/remark | AdminOrderController@remark | 订单备注 | order:remark |
| GET | /api/v1/admin/orders/logs | OrderLogController@index | 订单操作日志 | order:log |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码默认1 |
| limit | int | 否 | 每页数量默认20 |
| keyword | string | 否 | 搜索关键词 |
| order_no | string | 否 | 订单号 |
| user_id | int | 否 | 用户ID |
| status | int | 否 | 订单状态 |
| pay_status | int | 否 | 支付状态 |
| start_date | date | 否 | 开始日期 |
| end_date | date | 否 | 结束日期 |

### 返回示例
```json
{
  "code":0,
  "data":{"total":1234,"page":1,"list":[
    {"id":1,"order_no":"TLL202609010001","user_id":1,"user_name":"张三","total_amount":"5199.00","pay_amount":"5199.00","status":2,"status_text":"待发货","pay_status":1,"pay_time":"2026-09-01 10:00:00","items":[{"product_name":"华为 MatePad","price":"5199.00","quantity":1}]}
  ]}
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |
| 10005 | 订单状态不允许此操作 |
| 10006 | 发货信息不完整 |

## 4. 操作流程
```
用户下单 → 待付款状态
├── 用户支付 → 待发货状态
│   ├── 管理员发货 → 待收货状态
│   │   └── 用户确认收货 → 已完成状态
│   └── 用户申请退款 → 退款审核
├── 用户取消 → 已取消状态
└── 管理员备注 → 添加内部备注
```

### 数据刷新机制
1. 页面加载加载订单列表
2. 搜索筛选变化立即刷新
3. 发货/备注后刷新订单状态
4. 新订单实时进入待发货列表

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 订单状态不更新 | 缓存或事务未提交 | 清除缓存检查数据库事务 |
| 发货失败 | 物流单号格式错误 | 检查物流公司和单号格式 |
