# 退款管理

## 1. 页面概述
### 功能描述
退款管理页面，支持查看所有退款记录、退款状态、退款金额。退款管理是财务对账和售后处理的重要功能。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 退款总数 | 所有退款记录数 | 衡量退款量 |
| 退款中 | 处理中退款数 | 及时处理提醒 |
| 已退款 | 已完成退款数 | 衡量处理效率 |
| 退款金额 | 累计退款金额 | 衡量退款成本 |

### 使用场景
1. 退款查询：查看所有退款记录
2. 退款处理：处理待退款申请
3. 财务对账：核对退款金额
4. 退款统计：查看退款率和趋势

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/orders/refunds | AdminOrderController@refundList | 退款列表 | refund:list |
| POST | /api/v1/admin/orders/refunds/{id}/audit | AdminOrderController@refundAudit | 退款审核 | refund:audit |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码默认1 |
| limit | int | 否 | 每页数量默认20 |
| keyword | string | 否 | 搜索关键词 |
| order_no | string | 否 | 订单号 |
| status | int | 否 | 退款状态 |
| start_date | date | 否 | 开始日期 |
| end_date | date | 否 | 结束日期 |

### 返回示例
```json
{
  "code":0,
  "data":{"total":89,"page":1,"list":[
    {"id":1,"order_no":"TLL202609010001","user_id":1,"user_name":"张三","amount":"5199.00","refund_no":"RF202609010001","status":1,"status_text":"退款中","pay_channel":"wechat","created_at":"2026-09-01 12:00:00","refunded_at":null}
  ]}
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |
| 10005 | 退款状态不允许此操作 |
| 10006 | 退款渠道调用失败 |

## 4. 操作流程
```
用户/管理员发起退款 → 待审核
├── 管理员审核通过 → 退款中（调用支付渠道退款）
│   ├── 支付渠道退款成功 → 已退款
│   └── 支付渠道退款失败 → 退款失败（可重试）
└── 管理员审核拒绝 → 已拒绝
```

### 数据刷新机制
1. 页面加载加载退款列表
2. 审核后刷新状态
3. 支付渠道回调更新退款状态

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 退款失败 | 支付渠道配置错误或余额不足 | 检查支付配置和账户余额 |
| 退款状态不更新 | 支付渠道回调未到达 | 检查回调地址和日志 |
