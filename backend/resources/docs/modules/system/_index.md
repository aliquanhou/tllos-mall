# 系统设置模块总览

## 模块概述
系统设置提供商城的各种配置管理，包括基础配置、支付配置、物流配置、配送方式、订单设置、交易设置、用户设置、网站设置、通知设置、短信配置、存储设置、支付场景、数据字典、热门搜索、定时任务、地区管理、快递模板、文件管理、系统缓存、系统信息、操作日志。

## 子模块
| 子模块 | 文档 | 说明 |
|--------|------|------|
| 基础配置 | basic.md | 站点基本信息 |
| 支付配置 | pay.md | 支付渠道配置 |
| 物流配置 | logistics.md | 物流接口配置 |
| 订单设置 | order.md | 订单规则配置 |
| 数据字典 | dict.md | 数据字典管理 |
| 操作日志 | log.md | 管理员操作日志 |
