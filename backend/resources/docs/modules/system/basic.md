# 基础配置

## 1. 页面概述
### 功能描述
基础配置页面，支持配置商城基本信息，包括商城名称、LOGO、客服电话、备案信息、版权信息等。基础配置是商城展示的基础信息，影响所有页面的显示。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 配置项数 | 该模块配置项数量 | 衡量配置完整度 |
| 已配置 | 已填写的配置项数 | 衡量配置完成度 |
| 最后修改 | 最后修改时间 | 衡量配置新鲜度 |

### 使用场景
1. 基础配置配置：查看和修改基础配置相关配置
2. 配置验证：保存后验证配置是否生效
3. 配置备份：导出配置用于备份
4. 配置恢复：导入配置快速恢复

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/system/config | SystemController@getConfig | 获取配置 | system:config:view |
| POST | /api/v1/admin/system/config | SystemController@saveConfig | 保存配置 | system:config:manage |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| group | string | 是 | 配置组：basic |

### 返回示例
```json
{
  "code":0,
  "data":{
    "config_key":{
      "field1":"value1",
      "field2":"value2"
    }
  }
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |
| 10005 | 配置保存失败 |

## 4. 操作流程
```
进入基础配置配置 → 查看当前配置
├── 修改配置项 → 填写新值
├── 保存配置 → 验证配置格式 → 写入数据库
├── 清除缓存 → 配置立即生效
└── 验证配置 → 在相关功能中验证配置是否生效
```

### 数据刷新机制
1. 页面加载加载当前配置
2. 保存后立即生效
3. 配置变化影响所有相关功能

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 配置不生效 | 缓存未清除或配置键错误 | 保存后自动清除缓存，检查配置键名 |
| 配置保存失败 | 配置格式错误或数据库异常 | 检查配置格式和数据库连接 |
