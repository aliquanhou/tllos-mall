# 操作日志

## 1. 页面概述
### 功能描述
操作日志页面，支持查看所有管理员的操作记录，包括操作人、操作时间、操作模块、操作内容、IP地址。操作日志是系统安全审计的重要依据，用于追踪操作行为和排查问题。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 日志总数 | 所有操作日志数 | 衡量审计完整性 |
| 今日操作 | 今日操作日志数 | 衡量今日活跃度 |
| 操作人数 | 今日操作人数 | 衡量管理活跃度 |
| 异常操作 | 标记为异常的操作数 | 风险监控 |

### 使用场景
1. 操作审计：查看管理员操作记录
2. 问题排查：根据操作日志排查问题
3. 安全监控：监控异常操作行为
4. 日志导出：导出操作日志用于存档

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/logs | OperationLogController@index | 日志列表 | system:log:list |
| GET | /api/v1/admin/logs/{id} | OperationLogController@show | 日志详情 | system:log:view |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码默认1 |
| limit | int | 否 | 每页数量默认20 |
| keyword | string | 否 | 搜索关键词 |
| admin_id | int | 否 | 管理员ID |
| module | string | 否 | 操作模块 |
| start_date | date | 否 | 开始日期 |
| end_date | date | 否 | 结束日期 |

### 返回示例
```json
{
  "code":0,
  "data":{"total":1234,"page":1,"list":[
    {"id":1,"admin_id":1,"admin_name":"admin","module":"商品管理","action":"新增商品","target_id":1001,"target_name":"华为 MatePad","ip":"192.168.1.1","user_agent":"Mozilla/5.0...","created_at":"2026-09-01 10:00:00"}
  ]}
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |

## 4. 操作流程
```
管理员操作 → 系统记录操作日志
├── 记录操作人/时间/模块/动作/对象
├── 记录IP地址和User Agent
├── 日志列表展示 → 按条件筛选
├── 日志详情查看 → 查看完整操作信息
└── 日志保留 → 按配置保留一定时间（如90天）
```

### 数据刷新机制
1. 页面加载加载日志列表
2. 新操作实时记录
3. 日志按时间倒序排列

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 日志记录缺失 | 日志中间件未配置或异常 | 检查日志中间件配置和数据库 |
| 日志太多加载慢 | 日志量过大未分页 | 检查分页配置，定期清理历史日志 |
