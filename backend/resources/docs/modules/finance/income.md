# 订单收款

## 1. 页面概述
### 功能描述
订单收款管理页面，支持查看所有订单收款记录，包括支付金额、支付方式、支付时间、对账状态。订单收款是商城收入的核心来源，财务对账的重要依据。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 收款总数 | 所有收款记录数 | 衡量交易规模 |
| 收款总额 | 累计收款金额 | 衡量总收入 |
| 今日收款 | 今日收款金额 | 衡量当日收入 |
| 待对账 | 待对账的收款数 | 衡量对账工作量 |

### 使用场景
1. 收款查询：查看所有订单收款记录
2. 财务对账：核对收款记录与支付渠道账单
3. 退款管理：查看和处理退款
4. 收入统计：按时间/支付方式统计收入

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/finance/income | FinanceController@income | 收款列表 | finance:income:list |
| GET | /api/v1/admin/finance/income/{id} | FinanceController@incomeDetail | 收款详情 | finance:income:view |
| GET | /api/v1/admin/finance/income/export | FinanceController@incomeExport | 导出收款记录 | finance:income:export |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码默认1 |
| limit | int | 否 | 每页数量默认20 |
| keyword | string | 否 | 搜索关键词 |
| order_no | string | 否 | 订单号 |
| pay_channel | string | 否 | 支付渠道 |
| pay_status | int | 否 | 支付状态 |
| start_date | date | 否 | 开始日期 |
| end_date | date | 否 | 结束日期 |

### 返回示例
```json
{
  "code":0,
  "data":{"total":1234,"page":1,"total_amount":"567890.00","list":[
    {"id":1,"order_no":"TLL202609010001","user_id":1,"user_name":"张三","pay_amount":"5199.00","pay_channel":"wechat","pay_channel_text":"微信支付","pay_status":1,"pay_status_text":"已支付","pay_time":"2026-09-01 10:00:00","transaction_id":"wx202609010001","reconcile_status":1,"reconcile_status_text":"已对账"}
  ]}

```

| 错误码 | 说明 |

## 4. 操作流程
```
用户下单 → 创建支付记录（待支付）
├── 用户支付 → 支付渠道回调 → 更新支付状态为已支付
│   ├── 记录交易号 → 支付时间
│   └── 订单状态更新为待发货
├── 财务对账 → 核对支付记录与支付渠道账单
│   ├── 对账成功 → 标记为已对账
│   └── 对账异常 → 标记为异常（人工处理）
├── 用户退款 → 创建退款记录 → 支付渠道退款
└── 导出报表 → 按条件导出收款记录
```

### 数据刷新机制
1. 页面加载加载收款列表
2. 新支付实时进入列表
3. 对账状态更新后刷新

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 收款记录缺失 | 支付回调未到达或延迟 | 检查支付回调日志和支付渠道账单 |
| 对账异常 | 金额不匹配或交易号错误 | 人工核对支付渠道账单和系统记录 |
