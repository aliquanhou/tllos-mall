# 商家结算

## 1. 页面概述
### 功能描述
商家结算管理页面，支持查看商家结算单，确认结算，查看结算记录。商家结算是多商户商城的核心财务流程，平台根据商家订单收入扣除佣金后结算给商家。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 结算单总数 | 所有结算单数 | 衡量结算规模 |
| 待结算 | 待确认的结算单数 | 及时处理提醒 |
| 结算总额 | 累计结算金额 | 衡量资金流出 |
| 今日结算 | 今日结算金额 | 衡量当日资金流出 |

### 使用场景
1. 结算单管理：查看各商家结算单
2. 结算确认：确认结算单并打款
3. 结算记录：查看历史结算记录
4. 佣金统计：统计平台佣金收入

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/finance/settlement | FinanceController@settlement | 结算列表 | finance:settlement:list |
| POST | /api/v1/admin/finance/settlement/{id}/confirm | FinanceController@settlementConfirm | 确认结算 | finance:settlement:confirm |
| GET | /api/v1/admin/finance/settlement-records | SettlementRecordController@index | 结算记录 | finance:settlement:record |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码默认1 |
| limit | int | 否 | 每页数量默认20 |
| keyword | string | 否 | 搜索关键词 |
| merchant_id | int | 否 | 商家ID |
| status | int | 否 | 状态 |
| start_date | date | 否 | 开始日期 |
| end_date | date | 否 | 结束日期 |

### 返回示例
```json
{
  "code":0,
  "data":{"total":45,"page":1,"list":[
    {"id":1,"settlement_no":"SET202609010001","merchant_id":1,"merchant_name":"官方旗舰店","period_start":"2026-08-01","period_end":"2026-08-31","order_count":156,"order_amount":"56789.00","commission_rate":"10.00","commission":"5678.90","settlement_amount":"51110.10","status":0,"status_text":"待结算","created_at":"2026-09-01 00:00:00","confirmed_at":null}
  ]}
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |

## 4. 操作流程
```
系统生成结算单（按周期/按商家）→ 统计周期内订单
├── 计算订单金额 → 扣除平台佣金 → 计算结算金额
├── 管理员查看结算单 → 核对订单和金额
│   ├── 确认结算 → 状态为已结算 → 商家余额增加
│   └── 结算异常 → 状态为异常（人工处理）
├── 商家查看结算记录 → 申请提现
└── 结算记录永久保存（不可删除）
```

### 数据刷新机制
1. 页面加载加载结算列表
2. 确认结算后刷新状态
3. 新结算单按周期生成

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 结算金额不对 | 订单统计错误或佣金率配置错误 | 核对订单明细和佣金率配置 |
| 商家余额没增加 | 确认结算时余额增加逻辑异常 | 检查余额变动逻辑和账户日志 |
