# 提现管理

## 1. 页面概述
### 功能描述
提现管理页面，支持查看用户和商家的提现申请，审核提现申请，确认打款。提现管理是商城资金流出的重要环节，需要严格审核确保资金安全。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 提现总数 | 所有提现申请数 | 衡量提现规模 |
| 待审核 | 待审核的提现数 | 及时处理提醒 |
| 提现总额 | 累计提现金额 | 衡量资金流出 |
| 今日提现 | 今日提现金额 | 衡量当日资金流出 |

### 使用场景
1. 提现审核：审核用户/商家的提现申请
2. 打款确认：确认已打款给用户/商家
3. 提现查询：按状态/金额/时间筛选
4. 风险控制：监控异常提现行为

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/finance/withdraw | FinanceController@withdraw | 提现列表 | finance:withdraw:list |
| POST | /api/v1/admin/finance/withdraw/{id}/audit | FinanceController@withdrawAudit | 审核提现 | finance:withdraw:audit |
| POST | /api/v1/admin/finance/withdraw/{id}/pay | FinanceController@withdrawPay | 确认打款 | finance:withdraw:pay |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码默认1 |
| limit | int | 否 | 每页数量默认20 |
| keyword | string | 否 | 搜索关键词 |
| user_id | int | 否 | 用户ID |
| status | int | 否 | 状态 |
| start_date | date | 否 | 开始日期 |
| end_date | date | 否 | 结束日期 |

### 返回示例
```json
{
  "code":0,
  "data":{"total":89,"page":1,"list":[
    {"id":1,"user_id":1,"user_name":"张三","user_type":"user","amount":"1000.00","fee":"10.00","actual_amount":"990.00","pay_channel":"alipay","pay_account":"zhangsan@example.com","status":0,"status_text":"待审核","apply_time":"2026-09-01 10:00:00","audit_time":null,"pay_time":null,"remark":""}
  ]}
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|

| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |

## 4. 操作流程
```
用户/商家申请提现 → 校验余额 → 创建提现申请（待审核）
├── 管理员审核 → 核对用户信息和提现金额
│   ├── 审核通过 → 状态为通过（待打款）
│   └── 审核拒绝 → 状态为拒绝（余额退回，通知用户）
├── 财务打款 → 手动转账到用户账号
│   ├── 确认打款 → 状态为已打款
│   └── 打款失败 → 状态为失败（余额退回）
└── 提现记录永久保存（不可删除）
```

### 数据刷新机制
1. 页面加载加载提现列表
2. 审核/打款后刷新状态
3. 新申请实时进入待审核列表

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 用户余额没退回 | 审核拒绝或打款失败时余额退回逻辑异常 | 检查余额退回逻辑和账户日志 |
| 打款失败 | 收款账号错误或渠道问题 | 核对收款账号，检查支付渠道配置 |
