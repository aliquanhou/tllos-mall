# 菜单管理

## 1. 页面概述
### 功能描述
菜单管理页面，支持创建和管理系统菜单，配置菜单图标、路径、排序、权限标识。菜单是后台导航的基础，也是权限控制的核心维度。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 菜单总数 | 所有菜单项数量 | 衡量菜单规模 |
| 一级菜单 | 顶级菜单数量 | 衡量模块划分 |
| 启用菜单 | 状态为启用的菜单数 | 衡量可用菜单 |
| 权限标识数 | 有权限标识的菜单数 | 衡量权限粒度 |

### 使用场景
1. 菜单创建：创建新的菜单项
2. 菜单配置：配置图标/路径/排序/权限
3. 菜单排序：调整菜单显示顺序
4. 菜单管理：编辑/禁用/删除菜单

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/menus | PermissionController@menuList | 菜单列表 | permission:menu:list |
| POST | /api/v1/admin/menus | PermissionController@menuStore | 新增菜单 | permission:menu:create |
| PUT | /api/v1/admin/menus/{id} | PermissionController@menuUpdate | 编辑菜单 | permission:menu:edit |
| DELETE | /api/v1/admin/menus/{id} | PermissionController@menuDestroy | 删除菜单 | permission:menu:delete |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| status | int | 否 | 状态 |

### 返回示例
```json
{
  "code":0,
  "data":[
    {"id":1,"name":"工作台","path":"/dashboard","icon":"dashboard","parent_id":0,"sort":1,"permission":"dashboard:view","status":1,"children":[]},
    {"id":2,"name":"商品管理","path":"/product","icon":"goods","parent_id":0,"sort":2,"permission":"product:view","status":1,"children":[
      {"id":3,"name":"商品列表","path":"/product/list","icon":"","parent_id":2,"sort":1,"permission":"product:list","status":1}
    ]}
  ]
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |
| 10005 | 菜单下有子菜单不能删除 |
| 10006 | 菜单路径已存在 |

## 4. 操作流程
```
创建菜单 → 选择父级 → 填写名称/路径/图标/排序/权限标识
├── 菜单排序 → 拖拽或输入排序值
├── 编辑菜单 → 修改菜单属性
├── 禁用菜单 → 该菜单及子菜单不显示
├── 删除菜单 → 该菜单下无子菜单时可删除
└── 菜单权限 → 配置角色时选择菜单权限
```

### 数据刷新机制
1. 页面加载加载菜单树
2. 增删改后刷新菜单树
3. 菜单变化影响所有用户的导航

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 删除菜单失败 | 菜单下有子菜单 | 先删除子菜单 |
| 菜单不显示 | 状态为禁用或用户无权限 | 检查菜单状态和用户角色权限 |
