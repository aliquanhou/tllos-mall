# 角色管理

## 1. 页面概述
### 功能描述
角色管理页面，支持创建和管理系统角色，配置角色权限，分配用户角色。角色是RBAC权限体系的核心，通过角色批量管理用户权限。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 角色总数 | 所有角色数量 | 衡量角色体系 |
| 启用角色 | 状态为启用的角色数 | 衡量可用角色 |
| 权限总数 | 所有权限点数量 | 衡量权限粒度 |
| 用户角色数 | 每个角色的用户数量 | 衡量角色分布 |

### 使用场景
1. 角色创建：创建新的系统角色
2. 权限配置：为角色配置菜单和操作权限
3. 用户分配：将角色分配给用户
4. 角色管理：编辑/禁用/删除角色

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/roles | PermissionController@roleList | 角色列表 | permission:role:list |
| POST | /api/v1/admin/roles | PermissionController@roleStore | 新增角色 | permission:role:create |
| PUT | /api/v1/admin/roles/{id} | PermissionController@roleUpdate | 编辑角色 | permission:role:edit |
| DELETE | /api/v1/admin/roles/{id} | PermissionController@roleDestroy | 删除角色 | permission:role:delete |
| POST | /api/v1/admin/roles/{id}/permissions | PermissionController@rolePermissions | 配置角色权限 | permission:role:permission |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码默认1 |
| limit | int | 否 | 每页数量默认20 |
| keyword | string | 否 | 搜索关键词 |
| status | int | 否 | 状态 |

### 返回示例
```json
{
  "code":0,
  "data":{"total":5,"list":[
    {"id":1,"name":"超级管理员","code":"super_admin","description":"拥有所有权限","status":1,"user_count":2,"permission_count":156,"created_at":"2026-08-01"},
    {"id":2,"name":"运营管理员","code":"operation","description":"商品和订单管理权限","status":1,"user_count":5,"permission_count":45}
  ]}
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |
| 10005 | 角色下有用户不能删除 |
| 10006 | 角色编码已存在 |

## 4. 操作流程
```
创建角色 → 填写名称/编码/描述
├── 配置权限 → 选择菜单权限和操作权限
├── 分配用户 → 将角色分配给用户
│   └── 用户获得角色的所有权限
├── 编辑角色 → 修改名称/描述/权限
├── 禁用角色 → 该角色用户暂时失去权限
└── 删除角色 → 该角色下无用户时可删除
```

### 数据刷新机制
1. 页面加载加载角色列表
2. 增删改后刷新列表
3. 权限变化实时生效

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 删除角色失败 | 角色下有用户 | 先移除用户或调整用户角色 |
| 权限不生效 | 缓存未清除或权限配置错误 | 清除缓存检查权限配置 |
