# 管理员管理

## 1. 页面概述
### 功能描述
管理员管理页面，支持管理后台管理员账号，包括创建管理员、分配角色、重置密码、禁用账号。管理员是后台系统的使用者，通过角色获得相应权限。

### 核心指标
| 指标 | 含义 | 业务价值 |
|------|------|----------|
| 管理员总数 | 所有管理员数量 | 衡量管理团队规模 |
| 启用管理员 | 状态为启用的管理员数 | 衡量活跃管理员 |
| 今日登录 | 今日登录的管理员数 | 衡量活跃度 |
| 操作日志 | 管理员操作记录数 | 衡量审计完整性 |

### 使用场景
1. 管理员创建：创建新的后台管理员账号
2. 角色分配：为管理员分配角色
3. 密码管理：重置管理员密码
4. 账号管理：禁用/启用/删除管理员账号

## 2. API接口清单（基于真实控制器实现）
| 方法 | 路径 | 控制器方法 | 说明 | 权限标识 |
|------|------|-----------|------|----------|
| GET | /api/v1/admin/admins | AdminController@index | 管理员列表 | admin:list |
| POST | /api/v1/admin/admins | AdminController@store | 新增管理员 | admin:create |
| GET | /api/v1/admin/admins/{id} | AdminController@show | 管理员详情 | admin:view |
| PUT | /api/v1/admin/admins/{id} | AdminController@update | 编辑管理员 | admin:edit |
| DELETE | /api/v1/admin/admins/{id} | AdminController@destroy | 删除管理员 | admin:delete |
| POST | /api/v1/admin/admins/{id}/reset-password | AdminController@resetPassword | 重置密码 | admin:reset-password |

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码默认1 |
| limit | int | 否 | 每页数量默认20 |
| keyword | string | 否 | 搜索关键词 |
| role_id | int | 否 | 角色ID |
| status | int | 否 | 状态 |

### 返回示例
```json
{
  "code":0,
  "data":{"total":8,"page":1,"list":[
    {"id":1,"username":"admin","nickname":"超级管理员","avatar":"https://.../avatar.jpg","role_id":1,"role_name":"超级管理员","phone":"138****8000","email":"admin@example.com","status":1,"status_text":"正常","last_login_at":"2026-09-01 10:00:00","last_login_ip":"192.168.1.1","created_at":"2026-08-01"}
  ]}
}
```

### 错误码
| 错误码 | 说明 |
|--------|------|
| 10001 | 无权限操作 |
| 10002 | 数据不存在或已删除 |
| 10003 | 参数校验失败 |
| 10004 | 数据库操作失败 |
| 10005 | 用户名已存在 |
| 10006 | 不能删除自己的账号 |

## 4. 操作流程
```
创建管理员 → 填写用户名/密码/昵称/手机号/邮箱 → 分配角色
├── 管理员登录 → 验证账号密码 → 记录登录时间和IP
├── 编辑管理员 → 修改昵称/手机号/邮箱/角色
├── 重置密码 → 生成新密码（管理员首次登录需修改）
├── 禁用账号 → 管理员无法登录
├── 启用账号 → 恢复登录权限
└── 删除账号 → 非超级管理员可删除（超级管理员不可删）
```

### 数据刷新机制
1. 页面加载加载管理员列表
2. 增删改后刷新列表
3. 登录信息实时更新

## 8. 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 列表数据为空 | 数据库无数据或筛选条件不对 | 检查筛选条件确认有测试数据 |
| 新增保存失败 | 必填字段未填或格式错误 | 检查表单校验查看错误提示 |
| 编辑回显不全 | 接口返回字段缺失 | 检查控制器返回字段 |
| 删除后仍显示 | 缓存未清除 | 清除缓存 |
| 管理员无法登录 | 账号被禁用或密码错误 | 检查账号状态，重置密码 |
| 删除管理员失败 | 超级管理员账号不可删除 | 超级管理员账号受保护不可删除 |
